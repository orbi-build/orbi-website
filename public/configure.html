配置引导

  1. 安装 Orbi GitHub App 完成 onboarding，取得租户 ID。
  2. 带上租户参数打开本页：/configure?tenant=<租户 ID>。
  3. 填写 provider、endpoint、API key 和模型，点击保存；保存后即可修改重存。

OpenAI 兼容 provider 标识，如 groq、local。

自定义 endpoint，如 https://api.groq.com/openai/v1 或 http://127.0.0.1:8080/v1。

本地 endpoint 可留空；保存后只显示脱敏值。

如 qwen/qwen3.8-27b。
