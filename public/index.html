基础设施

Orbi 是用来建设和运行 AI 软件工厂的基础设施——软件工厂的工厂。

GitHub 上丢一张 Issue。后面的实现、测试、review、合入和发版，由 Runner 接着跑。

打开 GitHub 看 v0.2.0

一张 Issue 进来之后

  1. 01 任务进入 Issue 标成 ai-ready。Runner 按 P0、bug、milestone 领取，不靠人派工。
  2. 02 Agent 实现 在独立 worktree 里改代码、跑测试、提交。写什么由 Agent 判断。
  3. 03 测试与 Review 另一场 session 审同一份 diff。能改就当场改，再出 verdict。
  4. 04 失败恢复 能自动救的失败停在同一张 PR。进程没了，现场还在 Issue 和 journal 里。
  5. 05 发布 一张 ai-release Issue：冻 base、对范围、跑测试、打 tag、出 GitHub Release。
  6. 06 监控 journal 心跳、一条 progress comment、Prometheus。不用一直盯终端。
