隐私 · Orbi Cloud

隐私政策

哪些数据会跨过托管服务边界，以及为什么。 本政策说明 Orbi Cloud 用哪些数据登录、运行交付、统计用量和处理订阅账单。

我们使用的数据

只处理服务需要的记录

连接 Cloud 时，我们会收到 GitHub 账号信息和你授权的仓库。即使只用 GitHub 登录、还没装 GitHub App，我们也会记下你的 GitHub 用户名和 GitHub 返回的已验证邮箱，这样开通卡住时我们能联系上你。对这些仓库，服务会处理运行交付所需的仓库元数据和记录，例如 Issue、PR、提交及运行结果。我们的后台把你的账号与仓库配置存入 Cloudflare D1，并记录交付用量，用于额度和计费。网站可能为了站点统计记录匿名访客事件：可见页面发生真实交互并达到 10 秒时记录 engaged，点击带标记 CTA 时记录 cta_click，区块进入视口时记录 section_view，以及记录本页最大 25/50/75/100% 滚动档位的 scroll_depth。浏览器会发送一个识别本次访问的第一方 cookie、页面路径、事件类型，以及 CTA、区块或深度详情；访问页面时还会发送落地页地址里的查询参数和来源页地址，两者都按原样记录。不收集表单内容或鼠标轨迹。为执行服务条款，我们可能查看相关的 Issue 内容和仓库内容。

我们发出的邮件（周报和写给你个人的邮件）里，指向 orbi.build 的链接会带一个随机编号。你点开链接时，这个编号会和落地页地址一起记下来，我们由此知道是哪位读者点了哪封信。编号本身不包含你的邮箱或名字。

网站还使用 PostHog 做产品分析和会话录像，以便看清访客实际怎么使用站点并据此改进。PostHog 会记录你打开的页面、你在页面上的操作，以及这段访问的录像——页面当时的样子和你点击了什么。页面通过我们自己的域名把这些记录发给 PostHog。欧盟、欧洲经济区、英国和瑞士的访客不在其内：转发路径会丢弃他们的事件，不会有数据到达 PostHog。

Cloud 交付会暂时运行在我们运营的基础设施上。交付结束后，工作副本会在 120 分钟没有活动之后删除；还在运行、或者等着继续恢复的交付会保留。Cloudflare D1 中的账号、仓库、用量和访客记录不会自动过期，会保留至服务运营不再需要或你提出删除请求。Issue、Pull Request 和 Release 仍然以 GitHub 上的记录为准。

服务供应商

让 Cloud 运转的处理方

Stripe 处理订阅付款、发票和客户门户操作；Orbi 不会收到完整卡号。对于没有配置自有模型密钥的 Cloud 订阅，默认使用 DeepSeek 的 deepseek-flash；DeepSeek 会收到交付所需的 prompt、相关仓库上下文和输出。配置了自有密钥时，则由你选择的模型服务商处理这些交付数据。服务商的数据保留与处理规则由其条款决定。GitHub 则按你授予的权限接收 Cloud 执行的 GitHub 操作。

托管运行环境运行在 Orbi 运营的 Vultr 机器上，并会在交付期间 clone 已连接的仓库。交付结束后，工作副本会在 120 分钟没有活动之后删除。

我们不出售个人信息。你带到 Cloud 的模型密钥加密存储在我们的后台，只在某次交付需要时交给它。

你的选择

访问、删除与联系

你可以在 GitHub 撤销 Orbi 的仓库访问权限。若要删除 Orbi 账号及关联的 Cloud 记录，请在 Telegram 私聊群管理员，并提供用于识别的 GitHub 账号。我们会说明删除了什么，以及哪些数据必须留在 GitHub 或 Stripe 系统中。

关于本政策、删除记录或停止邮件的问题，都请优先在 Telegram 私聊群管理员。不方便使用 Telegram 时，备用邮箱为 privacy@orbi.build。不想收到这类邮件的话，直接回复邮件或写信到 privacy@orbi.build，我们会删除这些记录。

本政策说明当前版本的 Cloud 如何处理你的账号、仓库、用量和访客记录；不承诺删除 GitHub、Stripe 或模型服务商独立持有的数据。
