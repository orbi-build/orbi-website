条款 · Orbi Cloud

服务条款

为托管交付线写清楚的约定。 使用 Orbi Cloud 即表示你同意合法使用服务、保护 GitHub 访问权限，并支付所选订阅。

服务

Issue 进来，经过审查的 PR 出来

Orbi Cloud 是面向你授权仓库的托管运行环境。它可以按 Cloud 页面所述执行交付：实现、独立审查与修复、审过的代码要在最新基线上 CI 通过才合并，以及 Release 证据。你仍负责仓库、指令、模型服务商以及对结果的检查。

付费档为 Solo（每月 US$__SOLO_MONTHLY_USD__，含 __SOLO_INCLUDED_TOKENS__ token）和 Pro（每月 US$__CLOUD_MONTHLY_USD__，含 __INCLUDED_TOKENS__ token）。新账号可__FREE_TRIAL__。未来订阅的用量和计划可能变化；你订阅时显示的价格和额度适用于该订阅。

订阅

计费与创始会员

银行卡订阅由 Stripe 处理，提供发票和客户门户，按你选择的周期每月或每年续费，直到你在门户中取消。支付宝和微信支付是按所购周期一次性付款，不会自动续费。创始会员享受永久 5 折，限 __FOUNDING_PARTNER_LIMIT__ 个订阅名额。折扣在订阅存续期间有效；名额用完后，新订阅按正价计费。

退款请求逐笔处理。请先在 Telegram 私聊群管理员，提供发票和退款原因；不方便使用 Telegram 时，可以发到备用邮箱 support@orbi.build。请先联系我们，再向发卡行申请撤销扣款。

使用限制

你不得用 Cloud 开发或运营什么

你不得使用 Orbi Cloud 开发、运营或支持：

  • 博彩、投注或彩票平台，包括其钱包、代理后台和结算系统；
  • 替他人转移资金的支付通道、洗钱或规避金融监管；
  • 诈骗、钓鱼或冒充他人；
  • 恶意软件，或未经授权访问系统或数据；
  • 在你或服务运营方所在地违法的任何项目。

为执行本条款，Orbi 有权（但没有义务）在需要时查看 Issue 内容和仓库内容。项目属于本节所列情形时，我们可以拒绝或中止任何交付，并暂停或终止访问，已付费用不予退还。

边界

可用性、终止与法律

Cloud 按“现状”和“可用”提供。我们不保证服务不间断、特定模型服务商、交付成功或生成的修改正确。对由指令、凭据、仓库内容、服务商故障或你合并/部署的修改造成的损失，我们不承担责任。

你可以随时停止使用 Cloud。若未付款、滥用、违法、安全风险或严重违反条款，我们可以暂停或终止访问。GitHub、Stripe 和模型服务商也可能适用各自条款。本条款适用服务运营方主要营业地所在国家或地区的法律，不适用法律冲突规则；你所在地强制适用的消费者保护不受影响。

我们就任何索赔承担的全部责任，以你在索赔前 12 个月内实际支付的费用为限。本条款中英文版本不一致时，以英文版为准。
