支持 · Orbi

从有用的报告开始支持

告诉我们发生了什么，适合公开时留下公开记录。 Cloud 支持渠道包括邮箱、GitHub Issues 和 Orbi Telegram 群。

联系

三种联系项目的方式

  • support@orbi.build：账号、隐私、计费和退款请求。
  • GitHub Issues：可公开的可复现 bug 和产品问题。
  • Telegram 群：社区讨论和快速补充上下文。

我们不承诺固定响应时间，会按能力阅读请求；完整的复现步骤和相关交付或发票编号有助于更快处理。

报告 BUG

请提供什么

请提供 URL 或仓库、Issue 或交付编号、大致时间、预期结果、实际错误和相关日志片段。公开发布前请删除 token、API key、私有代码和个人数据。安全问题或私密账号事项请发邮件，不要发公开 Issue。

计费

退款请求

请把 Stripe 发票 ID、GitHub 账号、扣款日期和原因发到 support@orbi.build。不要发送卡号。我们会审核并回复决定；请在 Stripe 客户门户中取消未来续费。

Orbi

不会随 Session 消失的软件生产。
