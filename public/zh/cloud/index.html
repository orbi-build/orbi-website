ORBI CLOUD 是什么

托管 Runner，GitHub 仍是唯一事实源

Orbi Cloud 跑的是与自托管 Orbi 相同的 GitHub 原生产线——Issue 进，Worktree、测试、独立审查与修复、精确合并——只是运行在由我们维护的基础设施上。你的工作流一点不变：Issue、PR 和发布证据都留在你自己的仓库里。

  • 交付闭环
    GitHub Issue 进，打好 Tag 的 Release 出

    能改代码、会重跑测试的独立审查，exact-head merge（只合并审过的那个 Head），再到冻结 SHA、打 Tag、发布 GitHub Release、关闭 milestone——你的仓库本来就懂这条闭环，不需要引入第二个工作区。

  • 模型
    模型用量包含在内，成本摊在明面上

    Solo 每月含 __SOLO_INCLUDED_TOKENS__ token，Pro 每月含 __INCLUDED_TOKENS__ token；对应额度用完后，新交付暂停，没有按 token 计费的超额账单。单次交付的实测成本就写在下面。

  • 运营
    恢复、合并门禁、独立审查

    交付产线的运营层，由我们承担。

  • 发版
    发版由你发起，Orbi 来执行

    发版从不是全自动。你开一张 release 票并打上 ai-release 标签——这个标签只有人能打。发版的测试验收就是你仓库的 CI 结果——release commit 上的 GitHub Actions check run——所以 CI 里放什么，决定了 Orbi 替你保证什么：放单测，它保证代码逻辑；放业务流程的 e2e，它保证业务闭环。不放 CI 也是一种选择：没有任何 check run 时，两道门禁都放行，release 照样能发——只是失去了唯一的测试验收闸门。之后 Orbi 冻结 SHA、打 Tag、发布 GitHub Release、关闭 milestone。

点击之后

从登录到交付第一个 Issue，只有四步

不用注册新密码，也不用迁移工作区。整条路径都在 GitHub 上：

  1. 01 用 GitHub 登录

    一次 OAuth 点击。仓库和账号都是你的，不需要单独的 Orbi 凭证。

  2. 02 安装 Orbi GitHub App

    选择允许 Runner 工作的仓库；随时可以在 GitHub 一侧撤销授权。

  3. 03 连接仓库

    连接第一个仓库，随后我们开通你的 Runner。前 __FREE_DELIVERIES__ 次合并交付免费——不用绑卡，不用订阅。

  4. 04 给一个 Issue 加上 ai-ready 标签

    打开 <repo>/issues/new?labels=ai-ready，写清楚要改什么，再加上这个标签。Orbi 会在 5 分钟内认领，并在执行过程中在 Issue 下留言。只有成功合并的交付计入终身额度；失败或未合并结束的交付会退还这次额度。

卡住的问题

01Cloud 有哪些档位？怎么取消订阅？

Cloud 提供免费、Solo 和 Pro 三档。创始会员永久 5 折，限 __FOUNDING_PARTNER_LIMIT__ 位。

登录后，Cloud 状态页有「管理订阅」，打开 Stripe 客户中心：取消订阅、更新支付方式、查发票都在那里完成；取消后本页订阅状态随之更新。

02额度用完会怎样？

Solo 每月含 __SOLO_INCLUDED_TOKENS__ token，Pro 每月含 __INCLUDED_TOKENS__ token。对应额度用完后，新交付暂停，没有按 token 计费的超额账单。

03一个订阅能接几个仓库？

Free 和 Solo 同时最多各接 __SOLO_REPOSITORIES__ 个仓库。连接另一个仓库会停用原来的，并为新仓库重新开通；原仓库有进行中的交付时，暂时无法更换。Pro 同时最多接 __PRO_REPOSITORIES__ 个仓库。达到上限后，先停用一个已连接的仓库，再连接新的仓库。

04你们能看到我的代码吗？

托管 Runner 会把你的仓库 clone 到我们运维的机器上——这就是托管的含义。GitHub 仍是唯一事实源：Issue、PR 和发布证据都留在你自己的仓库里。GitHub App 授权哪些仓库由你选，随时可以在 GitHub 一侧撤销。

保留：交付进入终态后，worktree 会在静默 120 分钟后销毁；进行中和可恢复的交付 worktree 会保留。

隔离：每个租户的代码、凭据和交付产物均与其他租户隔离。

模型 API key：BYOK 密钥在控制面以 AES-GCM 加密存储；API 读取只返回掩码值，解密只用于注入 Runner。

05创始会员优惠包含什么？

创始会员永久 5 折，限 __FOUNDING_PARTNER_LIMIT__ 位；结账时输入 __FOUNDING_PROMO_CODE__。Free、Solo、Pro 三档的额度不变。

06自托管和 Cloud 能同时用吗？

可以。Orbi 以 AGPL-3.0 开源；若你的政策不允许 AGPL，也可选 Sustainable Use License。两种许可下自托管都免费。Cloud 是跑在我们维护的基础设施上的托管 Runner。订阅 Cloud 并不取代自托管，自托管也不需要 Cloud 订阅。

07Orbi Cloud 出故障了怎么办？

故障会发布在公开的状态页 status.orbi.build 上，页面展示实时状态和最近 60 天的历史记录。
