您好，我是 Orbi 的创始人 Lawrence。这周，Orbi 的交付进展可以直接发到 Telegram；自己部署的用户，也能用 Follow 模式在终端实时跟进。

设置 Cloud 的 Telegram 通知 →

Telegram 通知和中文评论

Orbi 卡住、要您补充信息、等您批准合并，或者合并了代码，都会给您发 Telegram 消息。Cloud 版在设置页打开，开源版 v0.7.1 起支持，见配置说明。

评论和 Telegram 消息用什么语言，现在可以在设置的「Orbi 消息语言」里选择。

开源版在终端里实时看进度

自己部署开源版的，用 orbi status --follow 就能在终端里实时看到 Issue 的进度（v0.7.0 发布说明）。

进度在同一页自动更新

状态页上的进度会自动更新到合并完成，不用您手动刷新。页面也重新排了版：每种状态只留一个主按钮，新账号的开通步骤改成对钩加进度条。

先在示例仓库里试一次

用官方模板在自己的 GitHub 账号下建一个示例仓库，就能让 Orbi 做一次小改动。下面这个例子，让 Orbi 给待办清单加上剩余项数：勾掉一项，计数从 3 变成 2。试一个官方示例，不占新账号的 3 次免费合并额度。
