VENDOR 背刺风险

便利不该等于交出边界

当零运维是第一优先级时，托管 agent 可以是正确选择。但它也把五个关键决定留给 vendor：定价、模型容量、数据接触、供给和账号访问。

风险已发生的案例Orbi 的取舍
涨价Managed Agents 在 token 价格之外增加 $0.08/session-hour。硬件和 provider 自选，无 session-hour 费用。
降级Anthropic 解释 OpenClaw 事件时说：“Capacity is a resource we manage thoughtfully。”在配置里切换 provider 或模型。
审计 / 数据云端 agent 执行时，代码、凭证和任务上下文经过 vendor 基础设施。代码、密钥和运行证据留在本地。
断供 / 政策2026-04-04 Anthropic 调整了 OpenClaw 的订阅通道；用户可能需要改用 API 计费或 Extra Usage。BYOK 跨 provider，避免单一供给切断。
账号访问托管服务的访问权和 ToS 解释权由 vendor 控制。不需要任何 agent vendor 账号。

托管 agent 的便利，以 vendor 的单方变更权作抵押。Orbi 把这五项风险留在你手里；代价是维护一台机器，收益是你可以自行改变运行方式，不必等待托管 vendor。

来源：Anthropic Managed Agents；Boris Cherny 公开声明；OpenClaw 深度对比；竞品调研 epic——核实于 2026-09-07。这些是所有权取舍，不是对服务质量的判断。
