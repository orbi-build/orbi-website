The clearest unit is one merged delivery — a pull request that merged — not an abstract token quota. Amounts use DeepSeek's official deepseek-flash pricing at off-peak rates: cache hit $0.003 per million tokens, cache miss $0.15 per million, and output $0.60 per million. What the sample covers: Cloud's usage records, one row per issue and branch, written by Pi sessions. A resumed run adds to its row; a new attempt on the same branch overwrites it. WHAT THAT MEANS IN MONEY

Cents per run (including unmerged work) at DeepSeek V4.1 Flash list prices

DeepSeek publishes its prices — deepseek-flash (DeepSeek-V4.1-Flash): off-peak, a cache hit is $0.003/1M tokens, a cache miss $0.15/1M, output $0.60/1M. READ THE LIMITS FIRST

Three things this page does not claim

  • MOSTLY OUR REPO
    This is a measured range — not a promise to everyone

    1354 of the 1511 deliveries are in Orbi's own repositories: Python, a full CI suite, and issues written to spec keep our context short. A repository with longer context, slower tests, or vaguer issues lands elsewhere in the distribution. Treat the tables above as what they are: a measured range.

  • CACHING IS LOAD-BEARING
    95.9% cache reads assumes the provider supports prompt caching

    The whole cost structure rests on cache hits. On an endpoint without prompt caching — where every token bills as a miss — the same work costs roughly an order of magnitude more. Check your provider before extrapolating.

  • TOTAL TOKENS, AS BILLED
    These are total tokens, cache reads included

    That is the line the provider actually bills. Counting only input + output would hide about 96% of the real consumption and flatter the number — the opposite of what this page is for.

WHY IT'S SO CHEAP

A cache hit costs 1/50 of a miss — and 95.9% of the work is cache hits

Each run re-reads the same repository context: the tree, the conventions, the issue, the failing tests. Prompt caching turns that repeated reading into billed hits at $0.003/1M instead of misses at $0.15/1M. That single ratio is why a full run — implementation plus independent review that can repair and rerun — costs cents. It is also the honest question to ask any BYOK agent vendor: what share of your tokens are cache hits, and what does your provider charge for each?
