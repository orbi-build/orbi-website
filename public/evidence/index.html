READ THE BOUNDARIES FIRST

What this page does not claim

  • PRIVATE REPOS
    orbi-website and orbi-cloud are private

    Deliveries on this website (including orbi-website #158, issue to production) and on the Cloud control plane are real work, but those repositories are private. This page does not link them. A clickable 404 is a broken promise.

  • NOT A QUALITY VERDICT
    Public records are not a restatement of intent

    This page does not convert a qualitative reading into a fact. It points at GitHub objects a visitor can open. Judgement of the loop belongs to the reader of those timelines.

  • NOT A PRODUCT
    This is not a vmark-class application

    A consumer app would prove that AI can write software under human supervision. That is already proven elsewhere. Orbi's distinct claim is the unattended delivery loop on a GitHub ledger. The records above are that claim's public samples, not a new product.

PROPOSAL · NOT SHIPPING

A public sample warehouse, later

The second gap is a public repository whose only job is evidence: tickets enter, the full loop runs, history stays public. That is cheaper than building a product, and it is the shape that matches the claim. It does not exist yet. This page does not invent a URL for it.

  • SHAPE
    Evidence, not a product

    One public GitHub repository. Issues in, review, merge, tagged releases out. The visitor watches the same ledger Orbi already uses. No consumer surface, no second brand, no vmark clone.

  • WHEN
    After the unattended loop is the default path

    Opening a sample warehouse before the engine's own e2e path is green would mint a 404 with a README. A later issue creates the repository when that path is the default, not this one.

  • NOT HERE
    No placeholder repository is linked

    A search of public orbi-build repositories on 2026-09-14 returned only orbi-build/orbi. Until a sample warehouse is public, this section stays a proposal.
