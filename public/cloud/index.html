WHAT ORBI CLOUD IS

A hosted runner — GitHub stays the source of truth

Orbi Cloud runs the same GitHub-native delivery line as self-hosted Orbi — Issue in, worktree, tests, independent review and repair, exact-head merge — on infrastructure we operate. Nothing about your workflow moves: the Issues, pull requests, and release evidence stay in your repositories.

  • THE LOOP
    GitHub Issue in, reviewed pull request out

    The loop your repository already speaks — no second workspace to adopt.

  • MODELS
    Your own model key

    The runner drives the model through your API key; model spend goes to your provider, at your rate.

  • OPERATIONS
    Recovery, merge gates, independent review

    The operational layers of the delivery line, run for you.

PRICING

Founding Pilot: US$15/month

Orbi Cloud is opening as a Private Beta with limited seats. The Founding Pilot price is US$15 per month for the managed runner — orchestration, recovery, and the merge gates included. Model usage stays on your own provider key, so that line is whatever your provider charges.

Self-hosting the open-source core remains free forever; the pilot subscription pays for the hosted line. Want to talk about fit first? Apply / contact us.

AFTER YOU CLICK

From sign-in to a delivered Issue in three steps

No new password, no workspace to migrate. The whole path is GitHub-native:

  1. 01 Sign in with GitHub

    One OAuth click. Your repositories, your account — no separate Orbi credential.

  2. 02 Install the Orbi GitHub App

    Choose which repositories the runner may work in; revoke at any time from GitHub.

  3. 03 Subscribe and connect a repository

    Pay the Founding Pilot subscription, connect the first repository, and we provision your runner — the first Issue can start.
