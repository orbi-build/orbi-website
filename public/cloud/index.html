WHAT ORBI CLOUD IS

A hosted worker — GitHub stays the source of truth

Orbi Cloud runs the same GitHub-native delivery line as self-hosted Orbi — Issue in, a working copy, tests, independent review and repair, the reviewed code merging once CI passes on the latest base — on infrastructure we operate. Nothing about your workflow moves: the Issues, pull requests, and release evidence stay in your repositories.

  • THE LOOP
    GitHub Issue in, tagged release out

    Independent review that repairs code and reruns tests, then the merge of the reviewed code once CI passes on the latest base, the frozen SHA, the tag, the GitHub Release, and the closed milestone — the loop your repository already speaks, with no second workspace to adopt.

  • MODELS
    Model usage included, cost in the open

    Solo includes __SOLO_INCLUDED_TOKENS__ tokens a month and Pro includes __INCLUDED_TOKENS__; when the applicable allowance runs out, new deliveries pause — there is no per-token overage billing. The measured cost of a delivery is published below.

  • OPERATIONS
    Recovery, merge gates, independent review

    The operational layers of the delivery line, run for you.

  • TRUST
    You never have to trust the AI

    Merges pass gates the model cannot open, a reviewer that did not write the code checks every change, Orbi does not train any AI model on your code, and you are not locked in to Orbi or to any AI vendor. See how Orbi keeps your repository safe.

  • RELEASES
    You start the release, Orbi runs it

    Releases are never automatic. You open the release Issue and apply the ai-release label — a label only humans set. The release's test acceptance is your repository's CI result — the GitHub Actions check runs on the release commit — so what you put in CI decides what Orbi guarantees: put unit tests there and it guarantees your code logic; put a business-flow e2e there and it guarantees the loop closes. No CI is a choice too: with no check runs, both gates pass and the release still ships — minus its only test-acceptance gate. Orbi then freezes the SHA, cuts the tag, publishes the GitHub Release, and closes the milestone.

before they start

01What are the Cloud plans and how do I cancel?

Cloud has two paid plans, Solo and Pro, and no credit card is required to start. Founding members receive 50% off forever; there are __FOUNDING_PARTNER_LIMIT__ places.

After you sign in, the Cloud status page has a subscription management control that opens Stripe's customer portal — cancel, update the payment method, and view invoices there. The status page updates after you cancel.

02What happens when the monthly tokens run out?

Solo includes __SOLO_INCLUDED_TOKENS__ tokens a month and Pro includes __INCLUDED_TOKENS__ tokens a month. When the applicable allowance runs out, new deliveries pause — there is no per-token overage billing.

03How many repositories can one subscription connect?

Solo connects up to __SOLO_REPOSITORIES__ repository at a time; Pro connects up to __PRO_REPOSITORIES__. Once you reach the limit, deactivate a repository on the connect page before connecting another.

04Can you see my code?

The hosted worker clones your repository onto machines we operate — that is what hosted means. GitHub stays the source of truth: Issues, pull requests, and release evidence remain in your repositories. You choose which repositories the Orbi GitHub App may access, and you can revoke that access at any time from GitHub.

Retention: once a delivery has finished — merged, failed, or abandoned — its working copy is deleted after 120 quiet minutes; deliveries still running, or waiting to resume, keep theirs.

Isolation: each customer’s code, credentials, and delivery records are isolated from every other customer’s.

Model API keys: a key you bring is stored encrypted (AES-GCM), the dashboard only ever shows a masked value, and the key is decrypted only when a delivery starts and needs it.

The full picture, from merge gates to model choice and what we do not promise, is on the trust and security page.

05What does the founding offer include?

Founding members receive 50% off forever. There are __FOUNDING_PARTNER_LIMIT__ places.__FOUNDING_DISCOUNT_NOTE__ USDT payments transfer the founding price directly, so there is nothing to enter. The offer does not change the Solo or Pro plan allowances.

06Can I self-host and use Cloud at the same time?

Yes. The core is open source under AGPL-3.0, or available under the Sustainable Use License if your policy rules out AGPL. Self-hosting is free under either. Cloud is the hosted worker on infrastructure we operate. Subscribing to Cloud does not replace self-hosting, and self-hosting does not require a Cloud subscription.

07What happens when Orbi Cloud has an incident?

Incidents are published on the public status page at status.orbi.build, which shows real-time status and 60 days of history.
