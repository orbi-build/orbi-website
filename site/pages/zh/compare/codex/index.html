Orbi vs OpenAI Codex

软件工程目标相同，边界不同。Codex 是 OpenAI 的云端软件工程 agent：通过 ChatGPT、CLI 或 GitHub 发任务，在隔离的云沙箱里执行。Orbi 则把 GitHub Issue 变成你自己机器上的审查后 PR，并使用你选择的模型端点。本页把取舍讲清楚，不假装有一个工具适合所有人。

什么是 OpenAI Codex cloud

OpenAI 在 2025 年 5 月以 research preview 发布 Codex：一个可并行处理多个任务的云端软件工程 agent。每个任务都有独立的云沙箱，仓库会预载进去，产出可以是 pull request。Codex 的入口包括 ChatGPT、Codex CLI 和 GitHub 集成，使用 OpenAI 自研的 Codex 系列模型。

来源：OpenAI《Introducing Codex》发布公告、Codex 文档——核实于 2026-09-07。

VENDOR 背刺风险

云端便利也会移动边界

云沙箱可以免去本地配置，让并行执行更方便。但这也意味着服务价格、模型供给、账号访问和仓库及任务上下文经过的基础设施由 vendor 控制。

涨价云端访问绑定 ChatGPT 套餐；Codex CLI/API 使用可能另行按 API 计费。套餐和用量政策可能变化。自托管需要自己的硬件；模型用量付给自选 provider，也可以使用provider 额度（如有）。
降级Codex 模型迭代、可用性、限额和限流由 OpenAI 决定。BYOK 支持任意 OpenAI 兼容端点，切换 provider 只需改配置。

CODEX COST · 价格核对于 2026-10-17

Codex cost：用 Codex 要花多少钱

Codex 没有单独的售价。要么随 ChatGPT 套餐使用，要么用 API key 登录、按 token 付 API 费用。2026-10-17 OpenAI 的 Codex 价格页列出的套餐如下（美元价）：

套餐价格包含的 Codex
Free$0/月适合简单编码任务；桌面 app 中可用 GPT-6 Luna，视逐步开放情况而定
Go$8/月轻量编码任务；桌面 app 中可用 GPT-6 Luna，视逐步开放情况而定
Plus$20/月网页、CLI、IDE 插件和 iOS 上的 Codex；GPT-6.1 Sol 与 GPT-6 Luna；自动代码审查、Slack 集成；可用 ChatGPT credits 追加用量
Pro$100、$200 或 $500/月包含 Plus 的全部内容；目前没有 5 小时限额；$500 档可用 Ultrafast 模式
Business每人每月 $20（按年付，至少 2 人）；按月付 $25管理后台、SAML SSO 和 MFA；更大的云端虚拟机；可用 credits 追加用量
Enterprise 与 Edu联系销售Business 的功能，加上 SCIM、EKM、RBAC、审计日志和数据驻留控制
API key按 API token 计费CLI、SDK 和 IDE 插件；没有 GitHub 代码审查、Slack 等云端功能

套餐买的是一份用量额度，不是固定的任务数。按 OpenAI 的估算，Plus 和标准 Business 每 5 小时可以发 15–160 条本地消息（GPT-6.1 Sol），换成 GPT-6 Luna 是 350–3,000 条。云端任务消耗的额度可能更多，另外还可能有每周限额。Plus 和 Pro 用户额度用完后可以购买 credits：GPT-6.1 Sol 每百万输入 token 扣 50 credits，缓存输入 2.5，输出 250。当前额度以用量面板为准。

用 API key 时，Codex 按 OpenAI API 价格计费。标准档、短上下文，每百万 token：

API 模型输入缓存输入输出
gpt-6.1-sol$2.00$0.10$10.00

长上下文请求更贵（gpt-6.1-sol 输入 $4.00、缓存输入 $0.20、输出 $15.00），Fast 模式是标准价的两倍，写入缓存另外计费（gpt-6.1-sol 每百万 $2.50）。OpenAI 也提醒，不要拿 API 单价去推算订阅里包含多少任务。用 Orbi 时，模型费用付给谁由你决定：自托管 Orbi 可以通过 Pi 的 openai-codex provider 使用你的 ChatGPT/Codex 订阅（见 Codex 指南），也可以填你自己的 key，接任意 OpenAI 兼容端点。成本页列出了我们自己的交付在 DeepSeek 上花了多少钱。

诚实判断

什么时候该选哪一个

选 CODEX，如果你要

把云端执行当作顺手的默认选项

  • 你已经是 ChatGPT 用户，希望从对话入口发起软件任务
  • 你想要多个独立预载沙箱并行工作，不想运维 runner
  • 你接受 OpenAI 云端执行、OpenAI 模型政策以及 ChatGPT 套餐（适用时 CLI/API 另行计费）
读 Codex 文档 ↗

选 ORBI，如果你要

让仓库本身成为任务队列

  • GitHub Issue、label 和 PR 已经是工作流，不需要第二个 workspace
  • 需要 BYOK、provider 额度（如有）或任意 OpenAI 兼容端点
  • 代码、密钥、状态和 agent 行为必须留在本地且可审计

Orbi Cloud 托管运行这套 GitHub 交付流程；自托管则把 Runner 留在你自己的基础设施上。
