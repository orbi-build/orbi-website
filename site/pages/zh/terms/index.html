服务条款

为托管交付线写清楚的约定。 使用 Orbi Cloud 即表示你同意合法使用服务、保护 GitHub 访问权限，并支付所选订阅。

服务

Issue 进去，经过审查的交付出来

Orbi Cloud 是面向你授权仓库的托管 runner。它可以按 Cloud 页面所述执行交付：实现、独立审查与修复、精确 head 合并和 Release 证据。你仍负责仓库、指令、模型 provider 以及对结果的检查。

当前计划为每月 US$__CLOUD_MONTHLY_USD__，包含__INCLUDED_TOKENS__ tokens模型用量。依据 FREE_DELIVERY_ALLOWANCE=3，前3 次 merged 交付免费。未来订阅的用量和计划可能变化；你订阅时显示的价格和额度适用于该订阅。

订阅

计费与 Founding 券

Stripe 处理付款、发票和客户门户。订阅会每月续费，直到你在门户中取消。Founding 券对最多 10 个 Founding 订阅提供100% off，在订阅存续期间有效；它不是另行支付的 __INCLUDED_TOKENS__ token 费用。Founding 名额用完后，新订阅按正价计费。

退款请求逐笔处理。请把发票和原因发到 support@orbi.build，不要先要求发卡行撤销扣款。

边界

可用性、终止与法律

Cloud 按“现状”和“可用”提供。我们不保证服务不间断、特定模型 provider、交付成功或生成的修改正确。对由指令、凭据、仓库内容、provider 故障或你合并/部署的修改造成的损失，我们不承担责任。

你可以随时停止使用 Cloud。若未付款、滥用、违法、安全风险或严重违反条款，我们可以暂停或终止访问。GitHub、Stripe 和模型 provider 也可能适用各自条款。本条款适用服务运营方主要营业地适用的法律，不适用法律冲突规则；你所在地强制适用的消费者保护不受影响。
