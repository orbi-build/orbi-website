  • v0.7.38
    Issue #2123, merged PR #2124, Release v0.7.38

    Orbi wrote its own ORBI_ACTIVE_MILESTONE Actions variable into every repository it delivered for — a variable only Orbi's own CI reads, and the reason its GitHub App asked for permission to write Actions variables. Filed as Issue #2123 in the public repository. Orbi stopped writing it, PR #2124 merged, and the change shipped in release v0.7.38 on 2026-11-06.

    What to look for on the timeline. The Issue timeline reads started, plan ready, PR opened, merged; the merged comment says how many review rounds ran and what the verdict was. PR #2124 has no human review and merged anyway — the review ran in an Orbi session independent of the one that wrote the code, and its result is written on the Issue. The Issue itself carries xqliu as its author; this run's own comments posted as Orbi's GitHub App, so they show as orbi-build.

  • v0.7.37
    Issue #2119, merged PR #2122, Release v0.7.37

    A suggestion from orbi suggest came with a reason naming Orbi's own input file: the repository owner was told the open Issues and PRs were both empty "in context.json", a file they never see.
