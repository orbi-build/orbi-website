Support · Orbi

Support that starts with a useful report

Tell us what happened and leave a public trail when it is safe. We support Cloud through email, GitHub Issues, and the Orbi Telegram group.

CONTACT

Three ways to reach the project

  • support@orbi.build for account, privacy, billing, and refund requests.
  • GitHub Issues for reproducible bugs and product questions that can be public.
  • Telegram group for community discussion and quick context.

There is no guaranteed response time. We read requests as capacity allows; a complete reproduction and the relevant delivery or invoice identifier help us act sooner.

REPORT A BUG

What to include

Share the URL or repository, Issue or delivery identifier, approximate time, expected result, actual error, and the relevant log excerpt. Remove tokens, API keys, private code, and personal data before posting. For a security report or private account matter, use email instead of a public Issue.

BILLING

Refund requests

Email support@orbi.build with the Stripe invoice ID, GitHub account, charge date, and reason. Do not send card numbers. We will review the request and reply with the decision; cancel future renewals in Stripe’s customer portal.
